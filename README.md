# Excel → SQLite 変換

Excel・CSV・SQLite のファイルを読み込み、1 つの SQLite ファイルに変換するツールです。
表の始まり（タイトル行を飛ばす）・ヘッダーの有無と段数・表の終わりを自動で判定し、プレビューの色で確かめてから保存できます。
変換した DB には SQL を実行でき、結果は CSV・Excel に出力できます。

データはブラウザの中だけで処理し、外部には送信しません。

---

## 1. 起動のしかた

1. フォルダごと任意の場所に置く
2. `index.html` を **ダブルクリック**（Edge で開く）

サーバー・ビルド・ライブサーバーは不要です。
次の部品は CDN から読み込むため、ネットワークへの接続が必要です。

| 部品 | 用途 |
|---|---|
| Font Awesome 6.5.2 | アイコン |
| SheetJS 0.18.5 | Excel の読み込み、結果の Excel 出力、サンプルの作成 |
| sql.js 1.8.0 | SQLite の作成・読み込み・SQL の実行（Web Worker で動かす） |

## 2. できること

| 機能 | 内容 |
|---|---|
| 読み込み | Excel（xlsx・xlsm・xls・xlsb・ods）／ CSV・TSV・TXT（UTF-8・Shift_JIS を自動判定、区切り文字も自動判定）／ SQLite（テーブルごとに取り込む）。ドラッグ＆ドロップ（画面のどこでも）・ファイル選択・Ctrl+V（ファイル、または Excel の範囲コピー）。複数ファイル可 |
| 開始位置 | 自動判定（タイトル・作成日などの行を飛ばす）、または行・列を指定。プレビューのセルをクリックして「ここを開始位置にする」でも指定できる |
| ヘッダー | 自動判定／あり（段数を指定）／なし。2 段以上は「大項目_小項目」の列名にする。ヘッダーなしの列名は `col1, col2 …` |
| 終わりの判定 | 空の行が N 行続いたら終わり、空の列が N 列続いたら終わり（N は変更可、初期値 2）。途中の空の行は取り込まない。末尾から ○ 行を除く（合計行など） |
| 結合セル | 左上の値を結合範囲のすべてのセルに埋める（ヘッダー・データとも） |
| 列 | 列名・型（整数・小数・文字・日付・日時・時刻）を自動で推定し、変更できる。取り込む列を選べる。名前も値もない列は自動で外す |
| 結合（まとめる） | 同じテーブル名にしたシート・ファイルは 1 つのテーブルにまとめる。取り込み元の列 `_source` を付けられる。列の構成が同じシートは「まとめ候補」として示す（下の「結合のルール」） |
| SQL で確認 | SELECT 文などを実行し、結果を表示（大量の行でも軽い）。テーブル・列名をクリックで差し込み、「条件の例」から書き方を選べる。履歴。結果を CSV（UTF-8 BOM 付き）・Excel に出力 |
| 保存 | `.sqlite` ファイルをダウンロード。作成される CREATE 文を事前に確認できる |
| プリセット | 読み取り設定（開始位置・ヘッダー・終わりの判定・列名と型・テーブル名）を保存。見出しが 80% 以上一致するシートを読み込むと自動で当てはめる |
| サンプル | 左下のフラスコから、パターン別に読み込み。「サンプルのみクリア」でサンプルだけを一括で外す |

### 自動判定のルール

| 判定 | ルール |
|---|---|
| 表の幅 | 先頭 1,000 行で、最も多く現れる「値のある列の数」 |
| 開始行 | 値のある列が表の幅の 6 割以上あり、下の行も同じくらいの幅で続く最初の行（1 つのセルだけのタイトルや、横に結合したタイトル行は飛ばす）。開始行をまたぐ縦の結合セルがあれば、その上端まで上げる |
| 開始列 | 開始行から 30 行の中で、最も左にある値 |
| ヘッダー | 先頭の行がすべて文字で、その下の列が主に数値・日付ならヘッダー。下に同じ形の文字の行が続けば 2 段目以降もヘッダー。縦の結合セルがあれば、その下端まで。すべて文字の表は、先頭の行の値がすべて異なり、下の行と重ならなければヘッダー |
| 終わり | 上の「終わりの判定」 |

### 結合のルール

| 場面 | 動き |
|---|---|
| ヘッダー | 追加する側のヘッダー行は取り込まない。追加する側でヘッダーを見落としていても、先頭行が既存の列名とほぼ同じ（8 割以上）ならヘッダーとして扱う。データの途中にあるヘッダーと同じ行（ファイルを継ぎ足したときなど）も取り込まない |
| 列の数が違う | 違いをメッセージで示し、「列を追加してまとめる」を押すと、新しい列を末尾に追加する。その列がないシートの行は空欄。「やめる」でまとめずに元のテーブル名に戻す |
| 列の名前が違う | 列は名前で合わせる。名前の違う列は別の列になり、その列がないシートの行は空欄（メッセージに「末尾に追加する列」「このシートにない列」として示す） |
| 違いの記録 | 「出力」パネルの結合の内訳に、列の数の違い（例：4→5 列）・追加した列（+）・ない列（−）・除いたヘッダー行の数を残す |
| 読み込みで結合 | プリセットなどで既にあるテーブルと同じ名前になったときも、列が違えばメッセージで知らせる（「別のテーブルにする」も選べる） |

### 型の推定と保存のしかた

| 型 | SQLite の宣言 | 保存のしかた |
|---|---|---|
| 整数 | INTEGER | 数。`1,234` のような桁区切りも数にする |
| 小数 | REAL | 数 |
| 文字 | TEXT | そのまま。`00123` のような先頭が 0 のコードは文字のまま残す |
| 日付・日時・時刻 | TEXT | `2026-10-15`／`2026-10-15 09:30:00`／`09:30:00`（SQLite には日付型がないため、並べ替えできる ISO 形式の文字にする） |

型に合わない値は捨てずに、文字のまま保存します。

## 3. 画面の構成

- **上部バー**：「取り込み」「SQL で確認」の切り替え、SQLite の作成状態、「SQLite を保存」
- **左のアイコン列**：押すと脇にパネルを開きます（もう一度押すと閉じる）。前回開いていたパネルを覚えています
  - ファイル／読み取り設定／列（名前と型）／出力／プリセット／（下段）サンプルデータ・使い方
- **取り込み**：シートの切り替え → 判定結果の要約 → シートそのままの表。色で範囲を示します（ヘッダー＝青、データ＝白、除外＝橙、範囲外＝灰、開始セル＝青緑の枠）
- **SQL で確認**：左にテーブルと列、右に SQL の入力欄と結果

入力欄は、入ると全体が選択され、Enter で確定して次の欄へ移ります。反映したことは、要約の行が光って知らせます。

## 5. 機能の足し方

役割ごとに登録簿を用意しているので、既存のファイルを変えずに足せます。

| 足したいもの | 方法 |
|---|---|
| 読み込み形式 | `js/io/readers/` に 1 ファイル足し、`X.readers.register({ id, exts, read })` |
| 脇パネル | `js/ui/` に 1 ファイル足し、`X.shell.panel({ id, icon, title, order, render, refreshOn })` |
| メインのタブ | `X.shell.view({ id, icon, label, el, onShow })` |
| 列の型 | `js/domain/types.js` の `TYPES` に 1 件足し、推定と変換に分岐を足す |
| サンプルのパターン | `js/sample/sample.js` の `PATTERNS` に 1 件足す |

足したファイルは `index.html` の `<script>` に追加します（読み込み順は「基盤 → 処理 → 入出力 → 画面 → app.js」）。

## 6. サンプルデータ

| パターン | 確認できること |
|---|---|
| 基本の表（社員名簿.xlsx） | 1 行目がヘッダー。日付・整数・コードの型の推定 |
| タイトル行あり（売上報告.xlsx） | タイトル・作成日を飛ばして B5 から開始。先頭が 0 の店舗コード |
| ヘッダーなし（作業ログ.xlsx） | ヘッダーなしの判定。日時の列 |
| 途中の空行・合計行・注記（在庫表.xlsx） | 1 行の空行は続けて読む、2 行の空行で終わる。合計行は「末尾から 1 行を除く」 |
| 2 段のヘッダー・結合セル（成績表.xlsx） | 「得点_国語」などの列名。データ部分の結合セルを埋める |
| 複数シート（月次売上.xlsx） | 同じ形の 3 シートを「まとめ候補」から 1 つのテーブルに結合。非表示シートは外す |
| 列が違う 2 ファイル（店舗別売上_11月.xlsx・店舗別売上_12月.csv） | 12 月のテーブル名を「店舗別売上」に変えると、列の違い（4→5 列、「来店数」「備考」を追加、「客数」なし）を知らせてから結合。12 月の途中にあるヘッダー行は取り込まない |
| Shift_JIS の CSV（顧客一覧_SJIS.csv） | 文字コードの自動判定。引用符・桁区切りのカンマ |
| SQLite（店舗マスタ.sqlite） | SQLite の読み込みと、Excel との結合（SQL で JOIN） |
| 大量データ（12 万行の CSV） | 10 万行を超える読み込み・作成・SQL の速さ |

## 7. 制約・注意

- Excel のセルの表示形式（例：数値に `00000` の書式を付けて `00123` と見せている）は読み取らず、値（123）を使います。先頭の 0 を残したい列は、Excel 側で文字として入力してください。
- Excel 出力は 1,048,575 行までです。それより多い結果は CSV で出力してください。
- 「SQL で確認」で INSERT・UPDATE などを実行すると、保存する DB にも反映されます。取り込みの設定を変えると、設定から作り直します。
- 中止（SQL の実行中）は Web Worker を作り直すため、作成済みの DB は次の実行時に作り直します。
